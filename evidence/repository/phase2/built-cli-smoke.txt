Usage: npm run watchdog -- inspect [--block <decimal block>] [--save-evidence]
       npm run watchdog -- risk [--warning <ratio>] [--critical <ratio>] [--target <ratio>]
                              [--config <thresholds.json>] [--block <decimal block>] [--save-evidence]
Default: a current block-pinned public demonstration position, checked by RPC and Chain MCP.
An explicit --block produces HISTORICAL evidence. Thresholds are exact decimal strings.
Risk estimates remain indicative and non-actionable; the selected oracle is UNVERIFIED.
